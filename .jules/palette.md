## 2026-05-10 - Missing Focus Rings on Native File Inputs
**Learning:** Native `<input type="file">` elements in this application's custom file-upload wrappers often lack visible focus indicators. While Tailwind resets remove default outlines, complex native inputs like file pickers can become entirely "invisible" to keyboard navigators when custom styling is applied without explicitly re-adding `focus-visible:ring-*` utilities.
**Action:** Always ensure that custom styled forms, particularly those using `<input type="file">` and custom buttons, explicitly implement `focus-visible` utilities to guarantee accessible tab navigation paths.
